# Personal Projects

A space for personal projects and experiments.

## Structure

Each project lives in its own subfolder:

```
personal-projects/
├── README.md
└── <project-name>/
    └── ...
```

## Adding a new project

1. Create a subfolder named after the project.
2. Add a short `README.md` describing what it does and how to run it.
3. Keep dependencies and setup notes inside the project folder.
